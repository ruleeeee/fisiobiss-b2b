# 🌿 FISIOBISS — Canal Mayorista B2B

Sistema de gestión B2B con **Google Sheets como base de datos**.

## Stack

| Capa | Tecnología |
|------|-----------|
| Frontend | **Next.js 14** + React 18 |
| Base de datos | **Google Sheets** (vía Service Account) |
| API | Next.js API Routes (servidor) |
| Gráficos | Recharts |
